Álgebra Vectorial y Números Complejos

Clase completa con teoría, métodos, ejercicios y modo examen interactivo

Conceptos Fundamentales

¿Qué es un Vector?

Un vector es una magnitud que tiene dirección, sentido y módulo (longitud). En el plano, se representa como un par ordenado \((x, y)\).

Notación de un vector en ℝ² \(\vec{v} = (x, y)\) donde \(x\) es la componente horizontal y \(y\) es la componente vertical

¿Qué es un Número Complejo?

Un número complejo es de la forma \(z = a + bi\), donde:

  • \(a\) es la parte real
  • \(b\) es la parte imaginaria
  • \(i\) es la unidad imaginaria, donde \(i^2 = -1\)
Dato importante Los números complejos generalizan a los números reales. Todo número real es un complejo con parte imaginaria igual a cero.

Operaciones con Vectores

1. Suma de Vectores

Para sumar dos vectores, se suman sus componentes correspondientes:

Suma de vectores \(\vec{a} + \vec{b} = (a_1 + b_1, a_2 + b_2)\)

2. Resta de Vectores

Para restar dos vectores, se restan sus componentes correspondientes:

Resta de vectores \(\vec{a} - \vec{b} = (a_1 - b_1, a_2 - b_2)\)

3. Multiplicación por Escalar

Multiplicar un vector por un número (escalar) multiplica cada componente:

Multiplicación por escalar \(k \cdot \vec{a} = (k \cdot a_1, k \cdot a_2)\)

4. Norma (Módulo) de un Vector

La norma es la longitud del vector, calculada con el teorema de Pitágoras:

Norma de un vector \(\|\vec{a}\| = \sqrt{a_1^2 + a_2^2}\)

Operaciones con Números Complejos

1. Suma de Complejos

Se suman las partes reales entre sí y las partes imaginarias entre sí:

Suma de complejos \((a + bi) + (c + di) = (a + c) + (b + d)i\)

2. Resta de Complejos

Se restan las partes reales entre sí y las partes imaginarias entre sí:

Resta de complejos \((a + bi) - (c + di) = (a - c) + (b - d)i\)

3. Multiplicación de Complejos

Se usa la propiedad distributiva y se recuerda que \(i^2 = -1\):

Multiplicación de complejos \((a + bi)(c + di) = (ac - bd) + (ad + bc)i\)

4. Conjugado de un Complejo

El conjugado cambia el signo de la parte imaginaria:

Conjugado \(\overline{a + bi} = a - bi\)

5. Módulo de un Complejo

El módulo es la distancia del origen al punto en el plano complejo:

Módulo de un complejo \(|z| = \sqrt{a^2 + b^2}\)
