Fundamentos

Teoría esencial

Las definiciones, propiedades y fórmulas que necesitas. Elige un bloque para no leer de más.

¿Qué es un vector?

Un vector es una magnitud con módulo (longitud), dirección y sentido. Geométricamente se representa por un segmento dirigido: el conjunto de todos los segmentos con la misma longitud, dirección y sentido forma un único vector libre.

En el plano se escribe por sus componentes:

Vector en ℝ² v = (x, y) = xi + yj

Si conocemos los extremos A(a₁, a₂) y B(b₁, b₂), el vector es AB = (b₁ − a₁, b₂ − a₂).

Operaciones básicas

Suma, resta y producto por escalar a + b = (a₁ + b₁, a₂ + b₂)
a − b = (a₁ − b₁, a₂ − b₂)
k · a = (k a₁, k a₂)
Interpretación La suma se dibuja con la regla del paralelogramo (o punta-cola). El producto por un escalar alarga (|k| > 1), acorta (0 < |k| < 1) o invierte el sentido (k < 0).

Norma y ángulo

Norma (módulo) ‖a‖ = a₁2 + a₂2

El ángulo entre dos vectores se obtiene del producto escalar y siempre cumple 0° ≤ θ ≤ 180°:

Producto escalar y ángulo a · b = a₁b₁ + a₂b₂ = ‖a‖ ‖b‖ cos θ
cos θ = a · b‖a‖ ‖b‖

Ortogonalidad, paralelismo y bases

  • Dos vectores son ortogonales si su producto escalar es cero: a · b = 0.
  • Son paralelos si existe un real λ tal que a = λb (componentes proporcionales).
  • Una base del plano son dos vectores linealmente independientes; todo vector se escribe como combinación lineal de ellos.
  • La base es ortogonal si sus vectores son perpendiculares, y ortonormal si además tienen norma 1 (es el caso de {i, j}).
Proyección de a sobre b proyba = a · b‖b‖2 b

El conjunto de los números complejos

Un número complejo es una expresión z = a + bi, con a, b ∈ ℝ. El conjunto se denota ℂ y contiene a todos los reales (cuando b = 0).

Unidad imaginaria i = −1  ⇒  i2 = −1
  • Forma binómica: z = a + bi, con a = Re(z) y b = Im(z).
  • Forma cartesiana: el par ordenado (a, b), que ubica el afijo en el plano complejo.
  • Es real puro si b = 0; es imaginario puro si a = 0 y b ≠ 0.
  • z₁ = z₂ ⇔ a₁ = a₂ y b₁ = b₂.

Conjugado, módulo y argumento

Conjugado y módulo z = a − bi   ·   |z| = a2 + b2

El módulo es la distancia del afijo al origen. El argumento θ es el ángulo que forma con el semieje real positivo, y queda determinado salvo múltiplos de 360°:

Argumento θ = arctan(ba) ajustado según el cuadrante

Forma polar y trigonométrica

Forma polar z = r(cos θ + i sen θ) = r eiθ

Teorema de Moivre y raíces

Fórmula de Moivre zn = [r(cos θ + i sen θ)]n = rn(cos nθ + i sen nθ)

Para obtener las n raíces n-ésimas se reparte el ángulo en n partes iguales:

Raíces n-ésimas zk = r [cos(θ + 360°kn) + i sen(θ + 360°kn)], k = 0, …, n−1
Geometría En forma trigonométrica, multiplicar gira y escala; dividir gira al revés y reduce. Elevar a n multiplica el ángulo por n.

Triángulos oblicuángulos

Un triángulo oblicuángulo no tiene ángulo recto. Se resuelve con dos herramientas: la ley del seno y la ley del coseno. En todo triángulo, la suma de los ángulos internos es 180° y se cumple la desigualdad triangular: cada lado es menor que la suma de los otros dos.

Ley del Seno

Lados proporcionales a los senos de sus ángulos opuestos asen A = bsen B = csen C = 2R

Se aplica directamente cuando conocemos dos ángulos y cualquier lado (AAS o ASA), o dos lados y el ángulo opuesto a uno de ellos (LLA).

El caso ambiguo (LLA)

Conocidos a, b y A, el seno de B puede no existir, dar un triángulo o dar dos:

CondiciónTriángulos posibles
sen B > 1Ninguno (no hay solución)
sen B = 1Uno: triángulo rectángulo (B = 90°)
sen B < 1 y b < aDos soluciones (B y 180° − B)
sen B < 1 y b ≥ aUna solución (ángulo agudo)
Ojo El ángulo mayor se opone al lado mayor. Si el ángulo que buscas es el mayor del triángulo, no puede ser obtuso y agudo a la vez: descarta la solución que no respete A + B + C = 180°.

Ley del Coseno

Generaliza a Pitágoras a2 = b2 + c2 − 2bc cos A
cos A = b2 + c2 − a22bc

Se usa de entrada cuando conocemos dos lados y el ángulo comprendido (SAS) o los tres lados (LLL). En el caso LLL, la regla de oro es calcular primero el ángulo mayor (el opuesto al lado mayor) para que el resto sean ángulos agudos.

Identidades fundamentales

Pitagóricas

sen2θ + cos2θ = 1
1 + tan2θ = sec2θ
1 + cot2θ = csc2θ

Cociente y recíprocas

tan θ = sen θcos θ
cot θ = cos θsen θ
csc θ = 1sen θ,   sec θ = 1cos θ
Signos por cuadrante sen es positiva en I y II; cos en I y IV; tan en I y III. El signo del seno y del coseno determina el cuadrante y, con él, el signo de las demás razones.

Medidas de tendencia central

Resumen un conjunto de datos con un solo valor representativo. Las tres medidas clásicas son la media, la mediana y la moda.

Media aritmética

Promedio x̄ = x₁ + x₂ + … + xnn = Σxin

Mide el valor de equilibrio del conjunto. Ventaja: usa toda la información. Debilidad: es muy sensible a valores extremos o atípicos.

Mediana

Es el valor central de los datos ordenados de menor a mayor:

Mediana Me = x(n+1)/2 si n es impar  ·  Me = xn/2 + xn/2+12 si n es par

Ventaja: resiste los valores atípicos, por eso es preferible en distribuciones sesgadas.

Moda

Es el valor que más se repite. Puede haber una moda (unimodal), dos modas (bimodal), varias (multimodal) o ninguna si todos los datos aparecen una sola vez.

Asimetría En una distribución simétrica coinciden media, mediana y moda. Con asimetría positiva (cola a la derecha) la media se desplaza a la derecha de la mediana: Mo < Me < x̄.

Varianza y desviación típica

La varianza mide la dispersión promedio respecto a la media: promedia los cuadrados de las desviaciones. La desviación típica es su raíz cuadrada y devuelve la medida a las unidades originales.

Varianza poblacional

Toda la población (N datos) σ² = Σ(xi − μ)²N

Se divide entre N porque se conocen todos los datos.

Varianza muestral

Una muestra (n datos) s² = Σ(xi − x̄)²n − 1

Se divide entre n − 1 (grados de libertad) para corregir el sesgo de la muestra.

Desviación típica σ = σ²  ·  s = s²
Fórmula abreviada de la varianza σ² = Σxi²N − μ²
Interpretación Una varianza o desviación típica pequeña indica datos concentrados alrededor de la media; una grande, datos dispersos. La desviación típica se expresa en las mismas unidades que los datos; la varianza, en esas unidades al cuadrado.
ConceptoFórmulaUnidadesCuándo se usa
Varianza poblacionalσ² = Σ(x−μ)²/Nunidades²Se conoce toda la población
Varianza muestrals² = Σ(x−x̄)²/(n−1)unidades²Datos de una muestra
Desviación típicaσ = √σ²unidadesComparar dispersión con los datos
Coeficiente de variaciónCV = σ/μ · 100 %%Comparar grupos con medias distintas
Ejemplo Para 4, 6, 8, 10 la media es 7; las desviaciones son −3, −1, 1, 3 y sus cuadrados suman 20. Entonces σ² = 20/4 = 5 y σ = √5 ≈ 2.24.

Las medidas de dispersión (rango, varianza, desviación típica) no buscan el centro, sino cuánto se alejan los datos de él. Se usan junto con las de tendencia central.
